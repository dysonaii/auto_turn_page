# Auto翻頁

給微信讀書（及任意閱讀 App）用的 Android 自動翻頁工具：每 N 秒點一下螢幕右中翻下一頁。免 root，靠無障礙 `dispatchGesture` 實現。

## 功能一覽

| 想做什麼 | 在哪操作 | 會發生什麼 |
|---|---|---|
| 自動翻下一頁 | 閱讀頁點懸浮球（▶→❚❚） | 每 N 秒點一次螢幕右中，預設 5 秒 |
| 調翻頁間隔 | 設定頁「秒數」3~30 秒 | 下一翻倒數重計 |
| 暫停／繼續 | 再點一次懸浮球（❚❚→▶） | 只停本次會話，服務保持開啟 |
| 看下一翻倒數 | 左側淡綠色進度條 | 由下往上長，滿了就翻頁；可在設定頁關掉 |
| 手動翻頁不亂跳 | 直接用手滑 | 偵測到內容變化，秒數重計 |
| 只在特定 App 翻 | 設定頁「選擇可翻頁的 App」 | 預設只勾微信讀書；全不勾＝全部允許 |
| 橫屏也在翻 | 把手機轉橫 | 點位按當下螢幕尺寸重算（API 30+ 取真實螢幕），球自動夾回可視範圍 |
| 調懸浮球深淺 | 設定頁「懸浮球透明度」10~100% | 即時生效 |
| 回設定頁改東西 | 長按懸浮球 600ms | 跳回設定頁；回設定頁自動停本次會話 |
| 確認手勢有沒有被系統擋 | 設定頁「測試點一下」 | Toast 顯示手勢 OK／被拒絕 |

## 開始使用（3 步）

1. 開 App →「1. 開無障礙權限」→ 啟用 Auto翻頁；「2. 開懸浮窗權限」→ 允許。
2. 設秒數、選白名單 App → 按「開啟翻頁服務」（只掛球，不開翻）。
3. 進閱讀 App 內文頁 → 點球變 ❚❚ 開始翻；再點（▶）即停。

realme／ColorOS 記得設成自動啟動＋省電無限制，否則 timer 會被砍。

## 安全停止（不用記，自動的）

* 三條件 AND 才翻：無障礙開＋翻頁服務開＋球點火；任一關即停。
* 自家設定頁內永不翻頁、綠條隱藏（球留著，長按回來改完再走）。
* 切去非白名單 App：停本次會話（球留著，點一下就回來）。
* 回到桌面：停本次會話＋球藏掉，重開本 App 才回來。
* 手勢被系統拒收（金融／遊戲頁）：自動停，免得空轉。

## 常見問題（看症狀）

* **球 ❚❚ 但不翻**：白名單有沒有勾該 App；剛切進書頁 3 秒內是校準期（安全視窗讀不到前景），等一下。
* **每次 Run 都要重開無障礙**：完整解除安裝會清系統綁定，屬 Android 設計。改用 ⚡ Apply Changes 或 `adb install -r` 覆蓋；重開後回無障礙打勾，上次狀態自動續翻。
* **按開始只跳設定頁**：無障礙還沒啟用，先啟用再按。

## 開發者

* 環境：Android Studio（Quail+）＋ SDK API 34；手機 Android 8+（`minSdk 26`）＋ USB 除錯。
* 編譯：Android Studio 開本資料夾等 sync → 接線 → Run ▶ 選手機。
* 檔案：`MainActivity.kt`（設定頁）／`PageTurnService.kt`（timer／手勢／懸浮球／進度條／門控）／`res/xml/accessibility_service_config.xml`。
* 原理：`AccessibilityService` 每 200ms 一輪，前景在白名單內才 `dispatchGesture` 點右中；前景判定看得見信 `rootInActiveWindow`，看不見（安全視窗）只信 3 秒內事件，過期放行。
